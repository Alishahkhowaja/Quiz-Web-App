# Quiz Web App

A fully responsive Quiz Web App built using HTML, CSS, and JavaScript. This app allows users to test their knowledge through interactive quizzes.

## Features

- **Interactive Questions** – Users can answer multiple-choice questions.
- **Real-Time Feedback** – Immediate indication of correct or incorrect answers.
- **Score Tracking** – Displays user score at the end of the quiz.
- **Responsive Design** – Optimized for desktops, tablets, and mobile devices.
- **Dynamic Question Rendering** – Questions are rendered using JavaScript.
- **Restart Option** – Users can retake the quiz.

## Technologies Used

- **HTML5** – Structuring the web application.
- **CSS3** – Styling the UI for a clean and responsive layout.
- **JavaScript** – Implementing the quiz logic, score tracking, and interactivity.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Alishahkhowaja/quiz-web-app.git
   ```
2. Open `index.html` in your browser.
